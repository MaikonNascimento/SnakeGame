🐍 Snake Game

Jogo da cobrinha desenvolvido em Java utilizando Swing com o objetivo de praticar conceitos de programação, orientação a objetos e criação de jogos 2D simples.

O projeto implementa uma versão clássica do Snake, onde o jogador controla uma cobra que deve coletar alimentos para crescer, evitando colisões e mantendo a maior pontuação possível.

🎯 Objetivo do Projeto

Este projeto foi desenvolvido como estudo para praticar:

Programação orientada a objetos (POO);
Manipulação de eventos de teclado;
Renderização gráfica utilizando Java Swing;
Criação de um loop de jogo utilizando Timer;
Organização de código em diferentes responsabilidades;
Controle de versões utilizando Git.
🚀 Tecnologias utilizadas
Java
Java Swing
AWT (Graphics, Point, eventos)
Git / GitHub

🎮 Como executar
Pré-requisitos
Java JDK instalado (versão recomendada: Java 8 ou superior)

Verifique a instalação:

java -version
Executando o projeto

Clone o repositório:

git clone https://github.com/MaikonNascimento/SnakeGame.git

Entre na pasta:

cd SnakeGame

Compile e execute o projeto pela sua IDE ou utilizando o Java.
